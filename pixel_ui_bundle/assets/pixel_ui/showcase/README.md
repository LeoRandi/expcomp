# Experimental UI skins

These source sheets support visual exploration on the debug UI showcase page.
They are also used by the runtime item-source styles: Raida uses the generated
Greenlands war-palisade atlas, Undiria uses the cave sheet, Koredull uses the
sci-fi sheet, and Falobris uses the water, sand, and grass coastal sheet.

- `sci_fi_tileset.png` came from `2D_Sci-Fi_Platformer_Tileset` and contains
  a coherent purple 3x3 panel frame.
- `purple_dungeon_tileset.png` came from
  `2D_Dungeon_Platformer_Tileset` and supplies amethyst masonry.
- `cave_tileset.png` came from `2D_Cave_Platformer_Tileset` and supplies warm
  rock blocks.
- `raida_palisade_atlas.png` is a curated 3x3 production atlas assembled from
  `tiles_16x16/01_praderas_campos/Greenlands_Tile_Set/GreenlandsTileset`.
  It combines packed-earth cells, capped rough-plank sequences, moss, vines,
  and stakes into a UI-specific frame while retaining the original 16x16 grid.
  Its first row contains the moss-and-stake joint followed by the beam start
  and middle; the second row starts with the beam end and two earth fills; the
  final row contains vine, tall-stake, and short-stake detail cells.
- `sheets_16grid/04_mar_costas/16x16_tileset_water_grass_and_sand/`
  supplies Falobris with a coherent 3x3 island edge: foamy water, pale sand,
  and a grassy interior.

The imported collection did not include license or attribution files. These
